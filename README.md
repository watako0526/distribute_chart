Before downloading and using any chart files from this repository, please read and follow the following guidelines:

### 1. No music files are distributed

This repository does **not** distribute any copyrighted music or music files.

To play a downloaded chart, please prepare the corresponding music file yourself in your local directory and adjust the offset and other settings as necessary.

### 2. Redistribution is strictly prohibited

Please do **not** republish or redistribute any chart files downloaded from this repository on any platform or through any other means.

### 3. Gameplay videos are welcome!

You are more than welcome to upload gameplay videos of the charts to any platform.

If possible, I would greatly appreciate it if you could include a link to this download page and a sample gameplay video in the description of your video. This would help more players discover and enjoy the charts!

### 4. Personal modifications are allowed

You are free to modify the downloaded charts for your own personal use and enjoy them locally.

However, please do **not** share or distribute modified versions of the charts on any platform.
